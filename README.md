# Silicone Materials Intelligence

## Deploy
1. Create/open the public GitHub repository `silicone-intelligence`.
2. Upload every file and folder in this package to the repository root.
3. Verify `.github/workflows/weekly-update.yml` exists on the `main` branch.
4. Settings > Pages > Source: GitHub Actions.
5. Actions > Weekly silicone intelligence > Run workflow.

If your computer hides `.github`, upload the package through a Git client, or create `.github/workflows/weekly-update.yml` in GitHub and paste the visible backup from `workflow-backup/weekly-update.yml`.
